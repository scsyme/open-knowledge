## 001 - Let domain structure emerge from the first experiment

For the first domain experiment, do not define a general Sudoku schema or settle the domain directory structure in advance.

Start with the smallest knowledge needed for one concrete Sudoku behaviour. Add structure only when the experiment provides evidence that it is useful or necessary.

This keeps the experiment focused on whether the knowledge is usable, rather than on designing a complete representation before it has been exercised.
